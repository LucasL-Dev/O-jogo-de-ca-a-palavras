# Side Quest

Caça-palavras em português com quatro universos de jogos, grades aleatórias de 12 × 12, seleção por toque, arraste ou teclado, cronômetro e três dicas por partida.

## Executar

Sem build ou dependências de aplicação. Na pasta do projeto:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Também é possível abrir `index.html` diretamente. As fontes do Google são opcionais; há fontes locais de fallback. Não utiliza imagens ou recursos oficiais das franquias. O progresso da partida é temporário e reinicia ao recarregar a página.
